# Cinematic Exposure v0.2.5-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 优化相机装配持握：机身前端抬起，左手托底，右手休息位下移；模型与所有交互位置共用倾斜姿态。
- 胶卷安装/拆卸改为右下方绕行，从机身下方送入或退出，避开已装闪光灯；松手、悬停和闪光灯安装后的撤手也调整路径。
- 拿着胶卷悬停其他附件时保持胶卷避让姿势；不隐藏闪光灯或改动任何附件数据。
- 同时约束握点和绕行路线的可达距离，避免手臂限距把路径拉回闪光灯。相机胶卷基础动作时长为 1.45 秒，仍受动画速度配置控制。
- 保留相机改装和暗房动画；暗房、冲印、照片及物品消耗/同步逻辑未改变。
- 增加隔离的纯 Java 几何回归检查，覆盖原版闪光灯、手掌/袖子/胶卷间距、路径连续性与平滑。不加载或启动 Minecraft。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 请重点验证已装闪光灯时连续装卸胶卷、快速切换附件、不同 GUI 缩放下的持握位置。资源包替换模型、极端视角及实际渲染穿模仍需游戏内确认；数学检查和编译成功不代表游戏内测试通过。
