# Cinematic Exposure v0.2.4-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 暗房胶卷放入/取出统一左手，成品右手；补充双手伸手距离限制，四个流程控制的手势改在照片边缘完成。
- 修正镜头、滤镜动作中旋转整条手臂的问题，保留附件旋转并增加收尾回位，约束小窗口下的相机握持距离。
- 库存右键相机打开 Exposure 原界面；手持相机潜行 + 右键打开沉浸界面。使用原菜单入口标记，不改物品或网络操作。
- 删除相机黄色定位点，在交互框内显示真实附件物品、数量和原版拖拽预览。
- 相机和暗房选择库存物品时，增加空手向下掏取、在下方拿到物品后返回的动画。已手持的附件直接安装，快速安装也有掏取过程。
- 保留暗房世界照片、持久物品、光照提示，以及沉浸相机的 HUD/EMI 隐藏。没有改照片、冲印、消耗或服务端验证。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 未执行 runClient/runServer。请重点验证：胶卷左右手一致性、四个按钮与镜头/滤镜收尾、快速换物或中断时的掏取、不同 GUI 缩放/资源包的手部贴合，以及库存右键/手持潜行右键的两种入口。极端侧身/缩放时距离限制可能使手指略离开物品，需要实测微调。编译成功不代表游戏内测试通过。
