# Cinematic Exposure v0.2.1-alpha

- 支持 Minecraft 1.21.1 NeoForge，依赖 Cinematic Interactions 0.18.12 与 Exposure 1.9.19，Java 21。
- 修复暗房静置物品只在场景内可见：使用方块实体渲染器读取 Exposure 原有同步库存，退出、离开再返回后继续显示；不新增存储、网络包或掉落物。
- 照片预览移至方块中央的三维台面，随方块朝向定位，保留图像比例。移除角落 HUD 照片。
- 冲印双手围绕照片两侧动作，可点击中央照片发起原冲印操作；台面边缘指示跟随实际冲印状态。
- 修复相机物品栏：按钮或 Tab 展开/收起，复用 Exposure 库存布局与贴图，接入原版容器的点击、拖拽、Shift 快速移动、双击归集和数字键换槽路径。相机与库存分区显示。
- 保留相机镜头、胶卷、闪光灯、滤镜的安装与拆卸动画。未扩展快门、取景器或支架功能。
- 所有照片生成、物品消耗、槽位验证及同步仍由 Exposure/原版菜单处理。多人环境客户端和服务端均需安装本附属。
- 本地 Java 21 编译及静态打包检查通过；本 Release 只在 GitHub Actions 构建成功后上传同次构建的可安装 JAR。
- **尚未经游戏内测试，需要玩家自行测试并反馈问题。** 重点验证四个朝向的照片、区块重载后的物品、光影与资源包、不同 GUI 缩放、拖拽/Shift 操作和多人同步。其他模组也注册 Lightroom BER 时可能需要额外兼容；触屏拖动回弹位置尚未适配三维附件目标。
