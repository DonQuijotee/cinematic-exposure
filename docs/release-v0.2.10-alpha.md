# Cinematic Exposure v0.2.10-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 相机改为斜向展示，让镜头接口更清楚；胶卷从机身顶部后缘向下插入，取出沿原路上提。
- 暗房普通持物跟随光标，靠近槽位逐渐对齐；跨区域时增加两手靠拢、交接、分开的递手过程。胶卷装卸与照片拿取期间锁定操作手。
- 相机操作手在机身外侧有限范围跟随光标，另一只手支撑；掏取和装卸结束衔接当前目标。
- 增加渐缓边界和可达距离限制，约束机身高度；相机工作区隐藏重复鼠标物品图标，库存抽屉和拖拽预览仍保留。
- 保留已实现的相机改装、暗房手部交互、负片逐渐显影和台面物品持久显示；不改变 Exposure 照片、附件、物品消耗或网络逻辑。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 不启动客户端/服务器。构建和纯数学检查不能验证动画观感、Mixin 实际注入、极端 GUI 缩放、快速换物/中断、光影及资源包模型兼容。原模型没有新增可开启的胶卷舱盖；距离约束不等于完整手臂碰撞系统。
