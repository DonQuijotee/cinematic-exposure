# Cinematic Exposure v0.2.13-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 相机改装采用与新版暗房一致的取放节奏：直接拿取附件，Shift 取出直接进库存，取消长拆卸与画面外掏取动作。
- 安装从机身近侧边缘开始；手中已有附件时直接承接当前手位。保留镜头/滤镜旋转和胶卷从顶部后侧插入。
- 安装与回手结束后才接受下一次物品操作，忙碌期间点击不排队；松手不会补执行被拒绝的放置。Esc/库存关闭正常。
- 相机机身与附件操作目标稍微移远，同时调整顶部通道，保持原模型大小和手臂长度限制。
- 保留已实现的相机改装动画、暗房冲印台动画、胶卷放下后出现预览、负片显影和相机闪烁修正。
- 附件、照片数据、物品数量、消耗与服务端验证仍由 Exposure 原逻辑处理。

本 Release 只在 GitHub Actions 完整编译及静态/纯数学检查成功后发布，附件来自同一次构建。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 未运行 Minecraft 客户端或服务器。请重点验证相机距离、装有闪光灯时装卷、普通/Shift/数字键安装、连续点击与松手、拖拽/触屏及资源包/光影兼容。
