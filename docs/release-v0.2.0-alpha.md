# Cinematic Exposure v0.2.0-alpha

- 支持 Minecraft 1.21.1 NeoForge，依赖 Cinematic Interactions 和 Exposure。
- 重做暗房：正式接入宿主工作站 API，复用走近、俯身、双手、库存抽屉与退出流程，替换旧 GUI 背景动画方案。
- 在台面直接放取胶卷、相纸、染料与照片，并操作冲印、帧选择和流程切换；保留 Exposure 图像预览。
- 重做相机改装：透明场景、机身附件热点、右手操作；下方只保留库存选择区。支持左右键与 Shift 点击，暂不支持拖拽分配、双击收集和数字键换槽。
- Lightroom 增加原 MenuProvider/方块坐标适配，多人两端都需要更新。
- 实际容器操作、照片生成、材料消耗和验证仍由原模组执行。
- **尚未经游戏内测试，需要玩家自行测试并反馈问题。** 编译成功不等于游戏内测试通过。
