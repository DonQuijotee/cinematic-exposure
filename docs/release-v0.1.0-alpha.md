# Cinematic Exposure v0.1.0-alpha

- 支持 Minecraft 1.21.1 NeoForge，构建基线 NeoForge 21.1.255、Java 21。
- 依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19；依赖不打包进附属 JAR。
- 已实现相机改装动画：左手持机，右手装卸胶卷、闪光灯、镜头和滤镜，镜头对准与旋转。
- 已实现暗房冲印台动画：胶卷放置与拿取、实际冲印时的双手动作、成品照片拿取。
- 保留 Exposure 原有 GUI 和照片预览，实际容器、冲印、消耗与网络逻辑仍由 Exposure 执行。
- 可分别关闭两个动画模块，可配置速度。
- **尚未经游戏内测试。** 编译成功只代表构建检查通过。
- 需要玩家自行测试并反馈问题，尤其是镜头/手部位置、资源包、光影、快速操作和服务器纠正后的表现。

此版本为 Pre-release。仅支持手持相机的改装窗口；相机支架及其他交互不在范围内。
