# Cinematic Exposure v0.2.3-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 相机界面隐藏原版快捷栏与常规 HUD，只保留 Cinematic 库存抽屉；退出后自动恢复。
- 相机界面不显示 EMI 侧栏、搜索框及按钮，也不让 EMI 配方快捷键接管；不更改 EMI 全局设置和其他界面。
- 胶卷交互点、悬停右手目标和装卸路径统一移至机身右侧，避免右臂为了取胶卷横穿机身。
- 保留已有相机托起、附件装卸、暗房台面照片、持久物品与光照提示。物品、照片与冲印逻辑不变。
- EMI 仍是可选模组；已静态核对 1.1.22/1.1.24 的 NeoForge 发布 JAR 方法。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 未执行 runClient/runServer。需重点验证 EMI 的实际隐藏和普通界面恢复、不同视角/资源包下的右臂轨迹，以及抽屉拖拽。编译成功不代表游戏内验证通过。
