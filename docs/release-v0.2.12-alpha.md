# Cinematic Exposure v0.2.12-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 暗房普通拿取直接更新原手持物，Shift 取出直接进入库存；移除额外取出、画面外掏取和显式递手动画。
- 空闲持物交给 Cinematic 原生光标跟随与左右手选择。Shift 放置从工作台近侧边缘取料，采用合成台式短程放下动作；已在手中的物品直接放入。
- 放置结束前阻止下一次台面/冲印/库存操作，不缓存或补发连点；Esc 和同步仍正常工作。
- 新胶卷实际落到台面后才显示其预览图，修复胶卷还在手中就出现新照片的问题。
- 保留已实现的相机改装动画、暗房冲印台动画、负片显影、台面持久显示；保留 v0.2.11 相机闪烁修正。
- 照片生成、数据、物品消耗及服务端验证仍使用 Exposure 原逻辑。

Java 21 编译及静态/纯数学检查通过。**本版尚未经游戏内测试，需要玩家自行测试并反馈问题。** 没有启动 Minecraft 客户端或服务器。

请重点验证普通/Shift 取放、放置期间连点与 Esc、胶卷落下后出现预览、左右手选择，以及光影/资源包/多人兼容。实际手位若不可达，动画会超时结束并恢复真实库存显示。
