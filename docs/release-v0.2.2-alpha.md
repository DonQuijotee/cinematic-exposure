# Cinematic Exposure v0.2.2-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 相机改装界面打开时，固定大小的相机由双手从下方托起，关闭时收回；不再凭空由小变大。
- 修正相机模型与手部路径的旋转方向，每次装卸固定附件接口坐标。镜头/滤镜先旋松、沿轴拔出，再移向右手；胶卷、闪光灯使用对应侧向路径。
- 相机物品栏复用 Cinematic 原有顶部玻璃抽屉：鼠标移入展开，移开收起，Tab 固定展开。继续使用 Exposure 容器与原版点击/拖拽/Shift 处理。
- 暗房工艺显示“常规／混色”，说明用途与折射条件；台面边缘提示光照充足/不足，悬停查看亮度要求和缺料原因。
- 保留暗房物品持久显示、台面照片与冲印动画。没有新增照片生成、物品消耗或网络协议。
- 客户端与服务端仍需要安装附属。新增适配基于上述依赖版本，第三方界面/光影模组仍需实测。

此 Release 仅在 GitHub Actions 构建与静态检查成功后上传可安装 JAR。**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 未启动 Minecraft 客户端或服务器。需重点验证不同朝向装卸、快速切换附件、GUI 缩放/拖拽、抽屉 Mixin 应用、天气与自定义光照阈值及多人同步。触屏拖动回弹仍未适配三维附件目标。
