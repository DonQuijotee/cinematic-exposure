# Cinematic Exposure v0.2.8-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 修复 v0.2.7 冲印时中央照片只显示一片白色的问题：改读 Exposure 客户端菜单实际同步的进度，而不是方块实体中过时的进度。
- 照片随冲印进度从相纸上逐渐显现；完成或取消后恢复完整预览，纸张和边框保持可见。
- 不改变照片数据、冲印时长、物品消耗及原网络同步；保留相机装配和暗房手部交互。
- 旁观者或退出菜单后仍显示完整图片；创造模式瞬时冲印即时显示。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 编译和静态检查不能验证实际显影观感或光影/资源包兼容。未启动 Minecraft，未执行 runClient/runServer。
