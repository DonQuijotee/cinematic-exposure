# Cinematic Exposure v0.2.7-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 暗房中央预览在实际冲印时从空白相纸逐渐显现，透明度随 Exposure 的真实同步进度平滑变化。
- 相纸和边框保持可见，完成/取消后恢复完整预览。退出场景后台面图片仍然显示。
- 不改变照片图像、冲印时长、物品消耗、服务端验证或网络同步；保留侧向相机装配与暗房交互。
- 淡入只在本机打开对应暗房菜单、能持续接收进度时启用；旁观仍显示完整预览。创造模式瞬时冲印维持即时显示。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 编译与静态检查不等于游戏内验证；透明混合、光影/资源包下的实际显影效果仍需确认。未执行 runClient/runServer。
