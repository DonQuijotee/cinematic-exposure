# Cinematic Exposure v0.2.9-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 移除暗房下方常驻光照条及图片下方闪烁条。光照是否达标仍可悬停“冲印”查看。
- 中央待冲印预览显示负片，随真实菜单冲印进度逐渐转为成片；相纸和边框保持可见。
- 输出槽存在对应成品时保持成片；取走成品、选择未冲印帧或取消且没有对应成品时显示负片。无胶卷时仍显示输出顶部照片。
- 复用 Exposure 负片效果与图片渲染，不改变照片数据、冲印规则、消耗或网络同步；相机装配和暗房手部交互保持。
- 旁观者显示由实际输出决定的静态负片/成片，不模拟未同步的进度。创造模式瞬时冲印直接显示结果。混色流程仅表现当前帧，不替代原模组的最终多层合成。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 编译与静态检查不能证明视觉效果；负片过渡、层叠混合及光影/资源包兼容需实测。未启动 Minecraft，未执行 runClient/runServer。
