# Cinematic Exposure v0.2.11-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 修复暗房纸张、四种颜料的普通放入/取出与 Shift 整组搬运动画；抽屉 Shift 直接委托 Exposure 原菜单快速转移，不重复操作。
- 台面静置物与手持物在实际接触时交接；原冲印自动消耗不再被视为搬运。离开后仍读取真实方块实体显示物品。
- 相机新操作立即接续当前手位，移除旧动作积压；掏取回程中可直接安装，确认同步包保留正在播放的动作。
- 手臂平滑状态持续保留，增加移动速度上限与掌面旋转连续性处理，针对动作开始/结束突跳和闪烁进行修正。附件到达接口后才交接显示。
- 暗房冲印从当前双手姿态过渡到照片边缘，左手扶纸、右手处理；保留负片到成片、斜向相机、顶部后缘装卷及原有配置。
- 已实现相机改装动画与暗房冲印台动画；照片生成、数据、物品消耗和服务端验证仍由 Exposure 执行。

已通过 Java 21 编译、打包/接口检查及不加载游戏的纯 Java 几何、交接和连续性检查。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 没有运行 Minecraft 客户端或服务器。请重点验证快速连续安装、确认包/延迟情况下的衔接、暗房 Shift 材料搬运，以及手臂闪烁是否消失；极端 GUI 缩放、光影、资源包和多人场景仍未验证。距离/速度约束不等于完整的手臂碰撞系统，无法到达目标时会结束视觉动作并恢复真实物品显示。
