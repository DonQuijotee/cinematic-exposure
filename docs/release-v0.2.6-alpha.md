# Cinematic Exposure v0.2.6-alpha

支持 Minecraft 1.21.1 NeoForge / Java 21，依赖 Cinematic Interactions 0.18.12 和 Exposure 1.9.19。

- 相机改为侧对玩家，镜头朝左、胶卷后部朝右；机身、附件、握点、交互目标及接口轴向同步旋转。
- 简化胶卷装卸：从右侧对准送入/抽出，删除下方绕行、多次折返和旧大仰角。
- 右手操作胶卷/闪光灯，左手操作镜头/滤镜，另一只手保持托住机身；掏取也使用对应操作手。
- 鼠标悬停仅高亮框，不再让手追随鼠标伸来伸去。
- 支撑位与持物位分开，安装后回位，取出后在机身外侧持物。胶卷基础动作时长缩短至 1.15 秒。
- 保留相机改装、暗房冲印台及原界面/沉浸界面入口；本次不修改暗房动作、附件数据、冲印或网络逻辑。

**尚未经游戏内测试，需要玩家自行测试并反馈问题。** 本地/Actions 编译和数学检查不能证明动画自然或完全没有穿模。请重点验证侧向构图、左右手持握、连续切换附件和资源包模型的实际观感。未执行 runClient/runServer。
